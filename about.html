About TunesReloaded Reworked

Original TunesReloaded message

This is TunesReloaded, a tool to make the process of managing your iPod's music a lot easier.

I started this project because of a passion to revitalize the music scene for these old iPod's.

Added in this variant (Reworked)

TunesReloaded Reworked is an alternative build focused on browser compatibility and reliability, especially for Brave users.

The goal is to avoid startup blocking, gate features by real browser capabilities, and provide clearer guidance when APIs like File System Access or WebUSB are unavailable.

Change list:

  • Brave compatibility improvements and clearer setup guidance in the browser compatibility modal.
  • Startup behavior changed to capability diagnostics, with connect-time API gating instead of startup blocking.
  • Filesystem sync race fix for sqlite tree copy order (iTunes Library.itlp -> iTunes Library -> iTunesControl).
  • Added explicit WebUSB availability guards and clearer error messaging in setup paths.
  • Fixed playlist/track context menu placement so actions appear at the cursor reliably.
  • Adjusted layout behavior for playlist and song list height coordination and scroll behavior.
  • Updated visible app title text to TunesReloaded Reworked.

The original TunesReloaded project is fully open source. Its source code is available at https://github.com/rish1p/tunesreloaded.
